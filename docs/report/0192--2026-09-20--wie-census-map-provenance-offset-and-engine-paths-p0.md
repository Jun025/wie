## 재고 — 제안의 전제 중 하나가 «관측»과 어긋났다

제안은 「전체 줄 주석은 고쳤으나 `foo(); // … /*` 형태는 그대로다」라고 남겼다. 그 진단은
정확하다. 그러나 **그 형태는 이 트리에 «0건»이다.**

400개 소스 파일에 현행 스트리퍼를 돌려 `inBlock` 전이를 전수로 셌다(2026-09-20):

| | 수 |
|---|---|
| 블록 상태 전이 | **17** |
| 그중 진짜 블록 주석(`/**` docblock · JSX `{/* */}`) | 16 |
| ★그중 거짓 전이 | **1** |
| 제안이 지목한 «혼합 줄»(`foo(); // … /*`) | ★**0** |

거짓 전이 1건의 정체가 이 회차의 실제 발견이다 — **`scripts/checker-census.mjs` 자신의 출력부**다.

```
scripts/checker-census.mjs:394 → EOF   (30 of 424 lines lost)
  console.log(`  population: scripts/*.{sh,mjs,js,py} · .github/scripts/**.{sh,mjs,js,py} · …`)
                                      ↑ 템플릿 리터럴 안의 `scripts/*` 가 `/*` 로 읽혔다
```

파일에 그 뒤로 `*/` 가 없어 **394행부터 EOF까지, 즉 Output 절 전체가 센서스에게 보이지 않았다.**
★**센서스가 자기 자신을 못 읽고 있었다.**

⇒ 판정: 제안의 **처방은 맞고 사례는 빗나갔다.** 고칠 것은 「`//` 뒤의 `/*`」가 아니라
**「블록 주석을 여는 `/*` 가 무엇인가」** 였고, 혼합 줄은 그 부분집합이다. 그래서 「`//` 만 더
보는」 패치가 아니라 **줄을 걷는 스캐너**를 썼다 — 두 형태가 한 판정에서 같이 닫힌다.

## 무엇을 바꿨나

`scripts/checker-census.mjs` 한 파일 · 제품 Rust 0줄.

1. **`scanLine(line, st)` 신설(약 40줄)** — `indexOf("/*")` 대신 줄을 문자로 걷는다. 아는 것:
   `//` · `/* */` · `""` `''` `` `` `` 리터럴(이스케이프 포함). ★**문자열 «내용»은 그대로 보존**하고
   주석 텍스트만 지운다 ⇒ 살아남은 줄이 기여하는 본문은 달라지지 않는다.
2. **줄을 넘겨 «이어지는» 상태는 블록 주석 하나뿐**이다. 백틱은 정규식 본문일 수 있어
   (`check-doc-liveness-parity.mjs:48` 이 마크다운 펜스 `` /^\s*```(\S*)\s*$/ `` 를 문다) 템플릿
   상태를 이어 주면 **인식 못 한 정규식 하나가 파일의 나머지를 삼킨다** — 지금 고치는 실패가
   자리만 옮긴 것이다. 줄마다 끊으면 어떤 오독도 **한 줄로 한정**된다.
3. **`*` 로 시작하는 줄을 버리던 휴리스틱을 제거**했다. 스캐너가 블록 상태를 알게 됐으므로
   불필요하고, 실측상 **Rust 역참조 31줄**(`*self.x = …` · 15파일)을 조용히 버리고 있었다.
4. **`★MIS-SCAN:` 보고 추가** — 파일이 «닫히지 않은 `/* …`» 상태로 끝나면 이름을 찍는다.
   소스는 주석 안에서 끝날 수 없으므로(컴파일이 안 된다) 그것은 **스캐너가 오독했다는 뜻**이다.
   ★**rc 는 바꾸지 않았다** — 이 파일의 헌장이 「센서스는 실패 상태가 없다」이고, 오독은 트리가
   아니라 **자기 수를 의심하게 만드는 사건**이다.

## 측정 — 세 방향의 조용한 오류를 고쳤고, 오늘의 출력은 «한 글자도» 안 바뀐다

문자열의 `/* … */` 가 옛 스트리퍼의 블록을 «닫아» 준다. ★**고친 뒤의 트리에서 고치기 전 결함을 재지 마라.**

## 숨기지 않는 대가

- ★**MIS-SCAN 가드는 «EOF까지 가는» 오독만 잡는다.** 뒤에 우연히 `*/` 가 있으면 조용하다 —
  실제로 M2 를 지금 트리에 돌리면 내가 **이번에 더한 메시지 문자열의 `/* … */`** 에서 닫혀
  16줄만 잃고 가드가 안 운다. ⇒ **하한 신호이지 증명이 아니다.** 그래도 오늘의 실결함은 잡는다.
- ★**스캐너가 모르는 것 3종**: 정규식 리터럴 · **중첩** 블록 주석 · 줄을 넘는 `"` `'` 문자열.
  실측 이 트리 기준 `/*` 를 품은 사례 **0 · 0 · 0**(`/\*/g` 형태는 오작동하지 않음을 따로 확인).
  ★**추정하지 않고 선언했다**, 그리고 미래분은 MIS-SCAN 이 (EOF까지 가면) 말한다.
- ★**제안이 경고한 「토크나이저는 이 파일의 크기를 넘어선다」를 정면으로 잰다**: 스캐너 본문은
  **40줄**이고 이 파일은 그 전에도 495줄 중 주석이 과반이다. 제안의 우려는 «정확한» 토크나이저
  (정규식·중첩까지)를 전제한 것이고, **셋을 선언으로 남긴 대가로** 크기를 그 안에 묶었다.
- ★**전용 시험 없음** — `scripts/*.mjs` 용 테스트 하네스가 이 저장소에 없다(선재). 개악은 전부
  «제품 호출부 실행»과 위 probe repo 로 냈고, probe repo 는 커밋하지 않았다(스크래치).
