## [2026-09-07] `wie_validate` 가 모으던 게스트 stdout 을 «옵트인으로» 싣는다 (wie-validate-drops-collected-guest-stdout)

**무엇을**: `--guest-stdout` 플래그 뒤에 JSON 두 키(`guest_stdout` · `guest_stdout_truncated`)를 **추가**했다.
★**기본값은 off 이고, 플래그가 없으면 두 키가 «아예 나오지 않는다»** — 기존 출력이 **바이트 동일**이다.

**왜 off 인가 — `Constraint 9` 판정이 «면책»이 아니라 «완화»이기 때문이다**:
게스트 «바이트»는 실리지 않지만 ★**게스트가 «찍는» 것은 실린다**. 같은 `AGENTS.md` 가 smoke-gate 절에서
「the committed baseline is **identifiers and expected status only, never paths or bytes**」라고 ★**경로를 바이트와 «나란히»** 금한다
⇒ 실게임이 경로를 찍으면 그것이 로그로 나간다. ⇒ ★**기본 off + 상한 4 KiB + 「실게임 출력은 저장소·공유 로그에 붙이지 마라」 경고**로 닫았다.
★**마스킹은 «채택하지 않았다»** — 경로를 다른 문자열과 구별하는 규칙은 취약하고, ★**그 규칙을 우회하는 문자열을 만드는 주체가 바로 게스트**다.

**★설계를 바꾼 실측 하나**: 이 출력을 파싱하는 **두 자리**(`smoke_gate.sh` · `lgt_render_probe.sh`)는 JSON 파서가 아니라
★**줄 «전체»에 `grep -o` + `tail -1`** 이다. ⇒ 게스트가 `"result":"PASS"` 를 찍으면 «나중 위치»라 위조가 이길 수 있었다.
★**JSON 이스케이프가 그것을 막는다**(`"` → `\"` 라 패턴이 요구하는 리터럴이 안 생긴다) — 그리고 그 성질을 **시험으로 잠갔다**.
★절단 사실은 ★**별도 키**로 알린다 — 본문 안 마커는 «경계를 씌우려는 그 주체»가 위조할 수 있다.

**사용자 영향**: 기본 동작 **무변**(판정 로직 무접촉 · 기존 키 무접촉 · 추가만). 진단할 때 `--guest-stdout` 를 켜면
게스트가 찍은 것을 **도구 출력에서 바로** 볼 수 있다 — 직전 회차가 그것 때문에 관측 자리를 네이티브 시험과 브라우저로 우회해야 했다.
