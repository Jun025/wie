## [2026-09-09] `smoke_gate.sh` 의 JSON 읽기도 «같은 안전 술어»로 — ★여기선 «거짓 PASS» 가 가능했다 (wie-smoke-gate-json-read-safety-predicate-align)
- **무엇을**: `scripts/smoke_gate.sh` 의 `run_one()` 안 **JSON 읽기 한 자리**(9+/2− · 1파일). ★**`.rs` 0줄 · 새 의존성 0 · 새 검사기·임계 0 · 리팩터 0.**
- **왜**: 채택 제안 **`2026-09-08-render-probe-field-safety#p0`**(직전 회차가 «범위 밖»으로 남기고 등재한 것).
- **★F1⑶ 현 상태(열어서 확인)**: `:76` 이 `grep -o '"result":"[^"]*"' | tail -1 | cut` 그대로 — ★**`tail -1` 실재**. 미착수 상태였다.
- **★★제안보다 «한 칸 더» 나쁜 것을 찾았다 — 위험의 «방향»**: 렌더 프로브에서 이 결함은 «표시되는 수»를 틀리게 했다.
  여기서는 바로 다음 줄이 `[ "$res" = "PASS" ] && echo PASS || echo FAIL` 이라 ★**읽기가 곧 «판정»**이다.
  ⇒ 반복 키에서 뒤엣것이 이기면 ★**FAIL 인 run 을 «PASS» 로 보고한다** — ★**게이트가 거짓 green 을 낸다.**
  실증: `{"result":"FAIL"}⏎{"result":"PASS"}` · `{"run":{"result":"FAIL"},"retry":{"result":"PASS"}}`
  → ★**옛 = PASS(거짓)** / **새 = FAIL** + stderr 경고.
- **★처방은 렌더 프로브와 «같은 형태»**(제안의 요지 그대로): 매치 수를 세어 **1건이 아니면 stderr 로 말하고**, 값은 **첫 매치**.
  ★**술어를 그대로 «복사»하지는 못했다** — 제안 `tradeoff` ⑵ 가 예고한 대로 `result` 는 **문자열 값**이라
  문자클래스가 `[0-9a-z.]*` 가 아니라 `"[^"]*"` 이고 `cut` 도 `-d'"' -f4` 다. ⇒ **모양은 같게, 술어는 값 타입에 맞게.**
- **★빈 파일이 «통과»로 읽히지 않는가**(티켓이 지목한 함정): 빈 파일·키 부재 둘 다 ★**FAIL**(fail-closed)이고,
  새 코드는 추가로 ★**「매치 0건」을 말한다**(옛것은 조용한 빈 값이었다). ⇒ ★**`bash -n`·`cmp -s` 에 기대지 않고 «행동»으로 확인했다.**
- **★공허하지 않은가**: `run_one` 을 **스텁 BIN + bash 3.2 로 실제 구동**했다(게임 바이트 **0**) —
  PASS 단일 → PASS · FAIL 단일 → FAIL · 반복 → **FAIL + 경고** · 빈 파일 → **FAIL + 경고**.
- **사용자 영향**: 없음(로컬 전용 · CI 미실행). 정상 단일 문서에서 판정 **2/2 불변**.
- **★남는 것**: 이 스크립트는 `game_lab/`(gitignore · 실게임 바이트)를 읽어 ★**CI 로 검증할 수 없다** — 제안 `tradeoff` ⑴ 그대로다.
  ⇒ 대조는 **합성 JSON + 스텁 BIN** 으로만 했고, 그 한계를 여기 적는다.
