- **무엇을**: 예외 «타입»만 잠겨 있고 «메시지»는 아무도 안 보는 상태에서 잠글지를 정했다. 실측 결과 대상 메시지는 **2개**이고 기계 독자는 **0**이지만, ★**둘이 같은 물건이 아니었다** — 하나는 리소스 이름을 **보간**해 정보를 나르고(`format!("Resource not found: {name}")`), 하나는 자기 예외 타입을 말로 다시 쓴 **상수**다(`"Failed to decode image"`). ⇒ ★**가지마다 다르게 답했다**: 전자는 ⒝**이름 토큰만** 잠그고(새 시험 1건), 후자는 ⒞**잠그지 않고** 이유를 기록했다.
