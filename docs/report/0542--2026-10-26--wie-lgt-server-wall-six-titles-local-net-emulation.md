## [2026-10-26] LGT 서버 벽 6종 — 엔진 안 가짜 서버로 3종 통과, 3종은 막힌 지점 기록 (wie-lgt-server-wall-six-titles-local-net-emulation)

**무엇을**: 문 닫은 게임사 서버를 엔진 프로세스 안에서 대신 답하는 층(`wie_backend::fake_server`)을 만들고, LGT WIPI-C 소켓 호출(`MC_netConnect`·`Socket`·`SocketConnect`·`SocketWrite`·`SocketRead`·`SetReadCB`·`SetWriteCB`·`SocketClose`)을 그 층에 이었다. 표에 오른 타이틀(AID)과 그 타이틀이 거는 호스트:포트에만 답한다. 표 밖 타이틀은 종전과 같은 길(접속 실패 콜백 · 소켓 -1)을 탄다. 버퍼를 읽거나 콜백을 내기 전에 fd 부터 가른다. 함께 고친 것은 두 가지다.

- 보내는 쪽: 24바이트 keep-alive(분류 `0xff`·하위 1)와 576바이트 로그인(분류 2·하위 0 · `PHONENUMBER`·`PHONEMODEL` 포함)을 보낸다. keep-alive 에는 답하지 않는다. 응답을 기다리는 곳이 없기 때문이다.
- **리듬팩 선택**: 응답만 붙인 빌드는 타이틀 → 메뉴 → «리듬팩 선택»까지 갔다. 거기서는 팩 이름과 그림이 비어 있었고, 확인을 누르면 `Invalid memory access` · PC=0 으로 죽었다(`f1/probe-reply-crash.txt`).
  - 그 화면은 stdlib `0x40a` 를 30초에 600회 넘게 부른다.
  - `strncmp` 를 넣자 팩 그림이 나오고, 난이도 → 노래 선택 → 노트 판 → «GAME OVER» 까지 갔다(`final/0093-play_caf9-restart_b9bf.png`).

**stdlib `0x40a` = `strncmp`** (`wie-lgt` `StdlibSvcId::Strncmp`). 근거는 두 가지다.
- 호출 모양: `(a, b, n)` 이고, 0 이 «같다»여야 위 두 판이 진행한다.
- 자리: 이 표는 C `<string.h>` 순서를 따른다(0x405~0x409 strcpy · strncpy · strcat · strncat · strcmp, 0x40b 부터 strchr… — #573 이 0x40b 에서 쓴 근거와 같다). strcmp 와 strchr 사이에 오는 것은 strcoll · strncmp · strxfrm 이다. 이 중 `(a, b, n)` 을 받고 같을 때 0 을 주는 것은 strncmp 뿐이다.
- 읽기는 각 쪽 `n` 바이트까지만 한다. `n` 안에 NUL 이 없는 버퍼도 C 에서는 합법이기 때문이다.

### 6. 함께 고친 것 — `sprintf`

- `3ff5948e235e` 의 헤더 `"@A%-8d%10.10s"` 가 서식 그대로 나갔다. `-` 와 `.` 를 «모르는 지정자»로 보고 통째로 출력했기 때문이다. C 의 뜻대로 왼쪽 정렬과 `%s` 정밀도를 읽게 했다. 이 판의 요청은 이제 `@A51      1911112222A_LGT_…` 다.
- 정수 정밀도는 C 대로 «최소 자릿수, 0 채움»이다. `%.2d` 의 5 는 `05`, `%.0d` 의 0 은 빈 문자열이 된다. 정밀도가 있으면 `0` 플래그를 무시한다. 첫 판은 정밀도를 읽고 버렸다(검수 F4).

- 응답 바이트는 실기 서버의 것이 아니라 «파서가 성공으로 읽는 최소»다. 계정 기록 40바이트·인증서 16바이트·0093 본문 0x48바이트는 모두 0이다. 게임이 이후 그 값을 랭킹 등에 보이면 빈 칸으로 보일 수 있다.
- 세 판의 랭킹·추가 통신(표에 없는 명령)에는 답하지 않는다. 그 기능은 종전처럼 시한 뒤 실패한다. 0093 의 «최신곡 받기»(다운로드)도 같다.
- 진도(progress) 축은 다시 재지 않았다(§5).
- 저장이 남는 브라우저에서 두 번째 실행은 `wie_validate --restart-at`(DB 유지)으로만 쟀고, 실제 브라우저에서는 재지 않았다. featurephone 셸은 DB 를 IndexedDB 에 저장하고, `audio.adt` 는 DB 다.
