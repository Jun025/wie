★**술어를 «지어내지 않고 검증했다»** — 선행 회차가 확정한 호출 시퀀스의 마지막 세 명령을 바이트로 유도하고 **두 known positive 에서 확인**했다:

```
01 21   movs r1, #1
18 68   ldr  r0, [r3]
13 6a   ldr  r3, [r2, #0x20]     ← table[8]
```

| 이미지 | 그 6바이트 출현 | 위치 |
|---|---|---|
| `01031C0A`(겟앰프드) | ★**1** | 파일 오프셋 `0x243c4` ⇒ guest `0x1243c4` |

`0x243c8: 13 6a` (2B) → `0x243ca: 0e f0 77 fd` = **4바이트 Thumb BL** → 복귀 `0x1243ce` → Thumb `LR = 0x1243cf`.
⇒ ★**기록된 `LR 0x1243cf` 가 정확히 설명된다**(site `0x1243c8` + 2 + 4 = `0x1243ce`, `|1` = `0x1243cf` ⇒ **델타 7**). `0103451A` 도 같다(`0x10571a` + 6 → `0x105720`, `LR 0x105721`). ★**`docs/report/0202` 의 한계 ⑵를 이 회차가 해소한다.**

### ★★구멍 둘 — 「전수」가 아니다. 그 사실을 먼저 적는다

**⑴ 스캔 못 한 2건은 «읽을 수 있다».**
`절묘한타이밍_01.00.05.zip`(567,566 B) · `정통맞고2007.zip`(813,473 B) — 둘 다 앞 8바이트가 **`50 4b 03 04`(PK)** 로 정상 zip 시작이고, ★**`unzip -l` 은 정상적으로 목록을 낸다**(각 6·7 파일). Python `zipfile` 만 「File is not a zip file」로 거부했다(중앙 디렉터리 뒤 잔여 데이터 등).
⇒ ★**「없다」의 모집단은 292/294 다.** 다음 회차는 `unzip` 경로로 그 2건을 메우면 된다 — **회수 가능한 구멍**이다.

**⑵ ★좁힌 술어는 «인자 배치»까지 고정한다.**
같은 slot 8 호출이라도 레지스터 배치가 다르면(예: `ldr r3,[r1,#0x20]`) 이 6바이트에 걸리지 않는다.
⇒ ★**좁힌 술어의 0건은 «부재의 증명»이 아니라 «하한»이다.** 그래서 넓혔다.
