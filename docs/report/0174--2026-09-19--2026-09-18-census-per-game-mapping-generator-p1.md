### ⒟ 대가 — ★「잃는 것이 없다」가 아니다

1. ★★**`awk` 로 6열을 훑는 독자에게는 «여전히 닿지 않는다».** 이 파일이 문서화한 작업 경로가
   `awk -F'\t' '$6 ~ /…/'` 인데 그 방식은 **주석 줄을 절대 만나지 않는다** ⇒ 네 면 중 **어느 것도**
   그 독자에게 닿지 않는다. 닫으려면 표식을 **행 안**에 넣어야 하고 그러면 모든 소비자의 데이터가
   오염된다 ⇒ **하지 않았고, 그 사실을 파일 머리에 적었다.** ★이 회차가 덮는 것은 「파일을 여는 독자」와
   「도구를 돌리는 호출자」이지 「헤더를 지나쳐 grep 하는 독자」가 **아니다**.
2. ★**여전히 검사가 아니다.** 출력이 `.gitignore` 라 CI 는 이 표를 보지 못한다 — 바뀐 것은
   「기계가 잡는다」가 아니라 「도구가 더 시끄럽다」뿐이다.
3. ★**부수효과 없던 도구에 «서브프로세스»가 생겼다.** `git` 2회 호출이 붙는다(그 두 호출만 실측 **0.27s** · 전체 실행 1.69s). git 이 없거나 얕은 클론이면 **항상 `UNMEASURED`** 가 되어 소음이 상시화될 수 있다.
4. ★**`ENGINE_PATHS` 가 «손으로 유지되는 목록»이다**(`wie_*`·`wie-*`·`Cargo.toml`·`Cargo.lock`·`data`).
   크레이트가 그 밖의 이름으로 생기면 **조용히 덜 세고**, 그 실패는 `CURRENT` 쪽으로 기운다
   (= 안전한 방향이 아니다). 기계가 지키지 않는다.
5. ★**`CURRENT` 일 때는 stderr 가 침묵한다** — 매번 우는 경고는 지나쳐진다는 판단이지만,
   「경고가 없다」를 「검사가 돌았다」로 읽을 여지를 남긴다(그래서 stdout·TSV 에는 `CURRENT` 도 찍는다).
6. ★**263 이라는 수는 오늘 값이다** — 이 리포트가 그 수를 박아 두는 순간 그것도 낡는다.
   ★도구는 매번 다시 세므로 **도구의 출력이 정본**이고 이 문서의 수는 «그날의 스냅샷»이다.

### ⒠ 게이트 — 내 출력, ★**그리고 «전부 캐시였다»는 사실을 숨기지 않는다**

`evidence/gates.txt` 에 rc 와 **소요 초**를 함께 적었다. `AGENTS.md` §Definition of Done 의
「무엇을 바꿨든 넷 다 돌린다」를 따라 전부 돌렸다.

```
gate1 cargo fmt --all -- --check                                    rc=0 (   1s)
gate2 cargo clippy --all -- -D warnings                             rc=0 (   3s)
gate3 cargo clippy --target wasm32-unknown-unknown -- -D warnings   rc=0 (   0s)
gate5 cargo +beta clippy --all -- -D warnings                       rc=0 (   4s)
gate4 RUST_MIN_STACK=4194304 cargo test --all                       rc=0 ( 726s)  "test result: ok" 46 · FAILED 0
```
★★**캐시 비를 «가려서» 적는다 — 「전부 캐시」도 「전부 실측」도 거짓이다.**
`fmt`·clippy 3축은 **따뜻한 캐시**에서 0~4초에 끝났다(형제 회차가 같은 워크트리에서 콜드 3분대로
돌려 둔 직후다) ⇒ ★**그 넷의 rc=0 은 «이 diff 가 안전하다»를 증명하지 않는다.** 반면 `gate4` 는
**726초 동안 46 블록을 실제로 실행**했다(컴파일만 캐시였다).
★**그리고 이 회차 diff 에는 Rust 가 0줄이므로**, 다섯 게이트 중 무엇도 이 변경을 겨누지 못한다 —
회귀가 있을 수 없는 자리에서 회귀가 없음을 확인한 것이다.
★**이 회차의 실제 검증은 위 ⒞의 개악 3축과 아래 검사기·회귀 대조**이고, 게이트는 계약 이행이다.
(수는 `evidence/gates.txt` 에 그대로 있다 — 「캐시가 아니었다」로 읽히지 않게 초를 함께 적었다.)
