## ★★판정 ⑴ — `merge=union` **기각**. 세 가지를 재서 골랐다
격리 워크트리(`git worktree add --detach origin/main`)에서 실제로 설정하고 병합했다 — 「설정했다 ≠ 듣는다」.

| 축 | 측정 | 판정 |
|---|---|---|
| ⒜ 로컬 `git merge`(워크트리) | 형제 착지 시뮬레이션 후 **rc=0 · 충돌 0 · 양쪽 항목 둘 다 보존** | ★**듣는다** |
| ~~⒝ `git merge-tree --write-tree`~~ | ★**들어냈다 — 아래 참조** | ★**판정 불가(무효 근거)** |
| ⒞ GitHub 서버 머지 (`POST /repos/:o/:r/merges`) | ★**HTTP 409 `Merge conflict`** — ★**merge-base 가 속성을 갖고 양쪽이 상속한 «착지 후» 형상에서** | ★**안 듣는다** |

### ★★[승계 `-fix` · 게이트② 반려 ①] ⒝ 는 «측정 착오»였다 — 내가 다시 재서 확인했다
초판 문면: 「`merge-tree` **rc=1**(양쪽 브랜치가 속성을 «보유»한 상태에서) ⇒ 안 듣는다」. ★**그 rc 는 브랜치를 말하지 않는다.**
`git merge-tree` 는 속성을 **워킹트리**(또는 `--attr-source`)에서 읽는다. 격리 클론 실측(`origin/main` × PR #196 — **같은 쌍**):

| 워킹트리 | rc |
|---|---|
| `.gitattributes` 없음 | **1** |
| ★**untracked** `.gitattributes` 한 장(★**양쪽 커밋에 없다**) | ★**0** |
| 그것을 지우면 | **1** |

⇒ ★**병합하지도 않는 파일이 디스크에 있느냐로 rc 가 뒤집힌다** ⇒ ★**그 rc 는 union 의 유효/무효를 «전혀» 말하지 못한다. 근거에서 뺀다.**

### ★그래서 기각은 ⒞ + 대가 위에 다시 선다 — ⒞ 를 «올바른 형상»으로 재측했다
★초판 탐침은 **merge-base(= `origin/main`)에 속성이 없었다** ⇒ 「서버가 어느 커밋의 속성을 읽어야 하나」가 애매한 형상이었다.
재측은 **`probe/u-base` 에 `.gitattributes` 를 커밋하고 그 위에 두 자식**을 뒀다 — ★**union 이 착지한 «뒤»의 실제 형상**이다.
```
POST /repos/Jun025/wie/merges  base=probe/u-a  head=probe/u-b   →  ★HTTP 409 Merge conflict
같은 쌍을 워킹트리에 속성을 둔 merge-tree 로                     →  rc=0   (속성 없으면 rc=1)
```
⇒ ★★**git 은 그 쌍을 깨끗이 합칠 «수 있는데» 서버가 그 능력을 쓰지 않는다** — 이것이 기각의 결정적 다리다.
★**남는 한계를 적는다**: 잰 것은 `POST /merges` 이고 `mergeable` 필드 자체는 아니다. 둘 다 **워킹트리 없는 서버 머지**라
직접적인 추론이지만 ★**«추론»이지 «측정»이 아니다**(별도 PR 을 열지 않으면 못 잰다 — 그 비용을 치르지 않았다).
★**그리고 머지 버튼이 수행하는 것이 바로 이 서버 머지**이므로, `mergeable` 이 무엇이든 **착지 자체가 이 409 를 통과해야 한다**.
⇒ `merge=union` 이 사는 곳은 «워크트리 머지» 하나뿐이고, 그것은 게이트③의 **손 해소 비용**만 줄인다(증상이 아니라 증상의 부작용).

### ★재발 방지(필수 3) — 이 회차가 먼저 지켰다
열린 PR 표를 뜨기 전 ★**`git fetch origin '+refs/pull/*/head:refs/remotes/origin/pr/*'` 를 «표와 같은 턴»에** 돌린다.
캐시된 ref 하나가 「15분 전부터 깨끗하던 PR」을 충돌로 적게 만든 것이 이번 ② 의 전부다. 같은 문장을 `AGENTS.md` 에도 넣었다.

### ★대가도 쟀다 — 「잃는 것이 없다」가 아니다
**⑴ 같은 줄을 양쪽이 다르게 고치면 «둘 다 조용히» 남는다**(rc=0 · 경고 0):
```
- 열린 형제 PR: #100 #102     ← theirs
- 열린 형제 PR: #100 #101     ← ours
```
★한 줄이어야 할 표가 **모순된 두 줄**이 된다. `STATE.md` 는 사람이 읽는 문서라 이것이 보인다.
**⑵ 순서가 «시간순»이 아니다** — 재현: PR 측 `2026-09-17` 항목이 main 측 `2026-09-18` 항목 **위**에 남았다(union 은 ours 를 먼저 쓴다).
★이 저장소의 원장 규약은 **「각 항목 회차의 작성 시각 순」**이라 그 규약과 **직접 어긋난다**.
**⑶ 도입 «그 병합»은 여전히 충돌한다** — 속성이 그 병합과 «함께» 도착하므로 한 번은 손으로 해소해야 한다(실측 rc=1).
