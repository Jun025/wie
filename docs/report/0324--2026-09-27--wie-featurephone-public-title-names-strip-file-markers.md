## [2026-09-27] featurephone 공개 게임 목록 — 표시 이름에서 파일 표식 제거 · 원 이름은 fileTitle 로 보존 (wie-featurephone-public-title-names-strip-file-markers)

**무엇을**
- `scripts/player-data.mjs` — `stripMarkers()`(파일 표식 제거) · `retitle()`(원 이름을 `fileTitle` 로 두고 `title` 을 정리 · 통신사 안에서 겹칠 때만 구별 표기). `import` 가 이것을 거친다.
  검사기에 두 규칙: **표식 잔존 0** · **통신사 안 표시 이름 중복 0** · `fileTitle` 필수. `--selftest` 개악 6건 추가(11 → 17 + 2 = 19규칙).
  모듈로 import 해도 CLI 가 돌지 않게 진입점 가드 1줄.
- `docs/player-data/compat.json` — 429종에 `fileTitle` 추가 · `title` 57건 변경. 등급·축·sha256 **불변**.
- `docs/contracts/featurephone-public-data.md` §1 — 표시 이름 규칙(구별 규칙 포함) · `fileTitle` 필드.

**왜**: #355 첫 판의 표시 이름이 파일 이름에서 와 `[큰화]`·`에디트`·판 번호·통신사 표기가 남았고, 같은 통신사·같은 이름 15묶음은 이용자가 구별할 수 없었다(총괄 방침: 표식은 빼고, 겹칠 때만 구별).

**사용자 영향**: 다음 엔진 릴리스로 셸 목록의 이름이 깨끗해진다. 같은 이름이 두 줄로 보이던 곳은 `(2)`·`(작은화면)` 등으로 갈린다.

### 수치
- 변경 **57**/429: 표식만 제거 **30** · 화면 크기/판 번호로 구별 **10** · 순번 `(2)` **17**(기존 중복 15묶음 + 표식을 빼자 생긴 겹침 2: KTF `지크`·LGT `영웅서기3`).
- 검사 전/후: 커밋된 첫 판을 새 검사기로 → **485 위반**(개악 red 실증) · 정리 후 **0**. `retitle` 재적용 = 동일(멱등).
- 빌드 산출물(`build --out`)을 셸 `validateCompat`(otterpebble `apps/featurephone/scripts/compat-import.mjs` · #1141 브랜치 판)로 → **위반 0**. 표식 잔존 정규식 0 · 통신사 안 중복 0.

### 순번 `(2)` 의 한계
표식이 없는 진짜 동명 파일(판이 다른 같은 게임)은 무엇이 다른지 이름에서 알 수 없어 순번뿐이다. 어느 쪽이 `(2)` 가 되는지는 sha256 순이라 의미가 없다 — 판 차이를 재서 이름을 붙이는 것은 이 회차 범위 밖이다.
