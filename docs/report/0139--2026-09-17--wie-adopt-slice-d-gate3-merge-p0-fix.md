못 충족한다」인데 ★**바로 아래 판정식에 콘솔 항목이 한 개도 없었다**. 지시대로 완주한 회차가 `NO-LEAK AUDIT: ✅`

## ⓐ ★«문서만 고칠까 · rc 까지 고칠까» — **rc 를 골랐다. 근거는 실측된 대가 0이다**

계약이 고르라 한 두 길:

| 길 | 얻는 것 | 대가 |
|---|---|---|
| ⑴ 문서 판정식만 | 사람이 읽고 판정 · 스크립트 무접촉 | ★**사람 규율이 된다** — 이 원장의 확정 교훈(「주석으로는 안 지켜진다」)이 그대로 적용된다. 직전 회차의 **45%** 가 정확히 그 교훈의 최신 표본이다 |
| ★**⑵ rc 에 반영** | ★**기계가 판정** — CI 의 배포 후 스텝(`web.yml` 마지막 스텝)까지 **자동으로** 같은 판정을 쓴다 | 기존 green 이 소급 red 가 될 수 있다 ⇒ ★**먼저 셌다** |

★**대가 실측 — 0건**:

| 표본 | 콘솔 에러(`[console.error]`+`[pageerror]`) |
|---|---|
| `web.yml` push 런 **최근 10건**의 `Verify the deployed app in a browser` 스텝 로그 전수 | ★**전건 0** (`NO-LEAK AUDIT: ✅` 도 10/10) |
| 이 회차의 손 별칭 실행(프로덕션) | **0** |

⇒ ★**뒤집히는 green 이 «하나도 없다»** ⇒ ⑴ 의 유일한 이점(무접촉)이 값을 잃는다. **⑵ 를 골랐다.**
★**숨기지 않는 대가**: 앞으로 프로덕션 페이지가 콘솔 에러를 내면 ★**배포 후 CI 스텝이 red 가 된다**(그 스텝은
`continue-on-error` 가 없다) — 그것이 **의도**이고, 소유자는 `AGENTS.md` 가 이미 정한 대로 **착지시킨 게이트③ 회차**다.

## ⓑ 산출물 — `rc=3` 을 새로 만들었지 기존 축을 건드리지 않았다

```
leak(off-origin ∪ 게임 헤더 바이트)  → rc=2   ← 종전 그대로
console.error + pageerror > 0       → rc=3   ← ★신설
그 밖                                → rc=0
```
★**관측부(`page.on("console")`·`page.on("pageerror")`)는 손대지 않았다** — 이미 옳았고, 그 줄들이 **잡아서 출력만**
하고 있던 것이 결함이었다. ⇒ ★**새 기계가 아니라 «이미 있는 출력을 판정에 넣은 것»이다**(신규 의존 0 · 추가 4줄).
`nonBlack`·누출 축 **무접촉**.

## ⓒ ★양방향 개악 대조 — **판정이 실제로 바뀐다**(문장만 늘어난 것이 아님)

`page.addInitScript(() => console.error(…))` 한 줄을 임시로 주입해 **같은 프로덕션 URL**에 3회 실행:

| 형상 | rc | 출력 |
|---|---|---|
| 현재(수정본) | **0** | `console errors (console.error + pageerror): 0` |
| ★**MUT**(콘솔 에러 1건 주입) | ★**3** | `[console.error] MUT injected console error` · `console errors …: 1` |
| 복원 | **0** | `console errors …: 0` |

★★**MUT 회차에서도 `NO-LEAK AUDIT: ✅` 는 «그대로 찍혔다»** — ⇒ ★**반려가 지목한 그 형상을 재현한 것이다**:
그 줄만 인용하면 «합격»으로 읽히고, 새 판정식(`rc=0` + 콘솔 0)으로 읽으면 ★**불합격**이다.
※MUT 는 임시 주입이고 **복원 후 백업과 바이트 동일**을 확인했다(`diff -q` identical · `git status` 에 잔재 0).

## ⓓ (2) `(45%)` — 괄호가 틀린 절에 붙어 있었다
