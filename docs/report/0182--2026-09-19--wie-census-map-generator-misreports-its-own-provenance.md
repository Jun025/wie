### 축 A — ★**채택 제안의 전제는 «이미 참이 아니다». 고치지 않고 그 사실을 적는다**

제안 `2026-09-19-census-rerun-leaves-per-game-rows#p1` 은 「헤더가 `statSync(...).mtime.toISOString()` 을 쓴다」고
적었고, 총괄 브리프는 「라벨은 `(LOCAL)` 인데 값은 UTC 다 — ★네가 그것부터 확인하라」고 했다. **확인했고, 아니다.**

- `toISOString` → `localDay` 교체는 **`3b73c63c`(PR #210, 오늘 착지)** 가 이미 했다(`git log -S` 2축 실측).
  그 커밋의 주석이 제안과 **같은 관측**을 인용한다 — 「a directory written at 05:26 KST reported the previous day」.
- 재현(스크래치 · 실 `game_lab/` 무접촉): 리포트 파일 mtime 을 **2026-09-19 05:26 +0900**(= UTC 로 09-18)으로 놓고 실행:
  `★reports mtime range (LOCAL): 2026-09-19 .. 2026-09-19` ⇒ ★**라벨도 LOCAL, 값도 LOCAL — 어긋나지 않는다.**

⇒ ★**제안이 지목한 병은 형제 회차가 이미 닫았다.** 그러나 제안의 `tradeoff` 가 예고한 **나머지 절반은 열려 있었다**:

| TZ | 같은 순간, 같은 파일 |
|---|---|
| `Asia/Seoul` | `2026-09-19` |
| `UTC` | `2026-09-18` |
| `America/Los_Angeles` | `2026-09-18` |

세 줄 모두 라벨은 `(LOCAL)` 이고, ★**읽는 사람에게 «어느 로컬인가»를 말하는 것이 아무것도 없다.**
두 열을 비교하는 회차는 「입력이 달라졌다」와 「기계가 달랐다」를 **구별할 수 없다.**

**처방 — 제안의 기본 권고(오프셋 동반)를 그대로 골랐다.** 이유: 라벨이 이미 `LOCAL` 이므로
«로컬 + 오프셋»은 라벨과 값을 **동시에 참**으로 만든다(UTC 로 되돌리면 라벨이 다시 거짓이 되고,
라벨을 UTC 로 바꾸면 디렉터리 이름(러너의 `date +%F`, 로컬)과 또 어긋난다). 대가는 줄 길이 **+6자**다.
결과: `2026-09-19+09:00` / `2026-09-18+00:00` / `2026-09-18-07:00` — ★**이제 세 표가 서로 환산된다.**

**⒞ 옛 TSV 비대칭 — 재생성하지 않았고, 헤더에 한 줄로 고지했다.**

### ★세 번째 결함 — 고치고 나서야 보였다: 센서스가 이 파일을 «못 읽고 있었다»

공유 모듈을 넣고 `checker-census.mjs` 를 돌리니 호출자가 **1건**(census 만)으로 나왔다 — 그런데 import 는 **둘**이다.

원인은 `sourceSurface` 의 **순서**다 — `/*` 를 먼저 찾고 `//` 판정을 나중에 한다:

```

```
⇒ ★**20–299행이 통째로 «보이지 않았다»** — 그 파일은 **아무것도 호출하지 않는 것으로** 계수돼 왔다(선재 결함).
`//` 줄은 블록주석을 열 수 없으므로 **판정 순서를 뒤집는 3줄**로 고쳤다. 센서스 출력 델타는 좁다:
`1 = 16 → 15` · `2+ = 18 → 19`(움직인 행은 `cargo-metadata.mjs` 하나) + `wie-j2me/tests/test_boot.rs` 의
named-not-run 참조 2건이 **새로 보이게** 됐다. ★**혼합 줄**(`foo(); // … /*`)은 **안 고쳤다** — 토크나이저가 필요하고,
그쪽은 같은 방향(과소 계수)으로 실패하며 이 파일은 이미 「0은 판정이 아니다」라고 선언한다.
