**0 으로 남고**, 게스트는 long 의 한쪽 워드를 **인스턴스 word 0** 에 쓴다. Card 자손에서 word 0 이 `canvas` 다.

계측(`DIAG-NULL`)으로 확인: 스파이더맨3 의 빈 슬롯 2개 = 클래스 `a` index 2 (앞 항목 `b:J`) · index 5 (앞 항목 `a:J`).
